What is connected today?

This first version is an original front-end workspace with local brief generation, copy/download and browser-local saving. It does not yet generate AI videos/images, publish social posts, send email, deploy apps or read analytics by itself. Those capabilities need authorized API integrations, service credentials, backend storage and usage/billing controls. Connect only services you have permission to use; third-party brand names and logos remain their owners' property.

Recommended build order: (1) project/account backend, (2) AI text API, (3) image/video provider APIs, (4) website code preview, (5) social/email integrations, (6) analytics and deployment controls.
